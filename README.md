# Set B – Student Record Management API

A REST API built with Node.js and Express.js to manage student records.
All records are stored in an in-memory JavaScript array. No database is used.

## Project structure

```text
StudentRecordManagement/
├── package.json
├── package-lock.json
├── server.js
├── httpServer.js
├── expressApp.js
├── README.md
└── screenshots/
```

## Setup and run

1. Open this folder in VS Code.
2. Install Express:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   node server.js
   ```

   Or:

   ```bash
   npm start
   ```

4. Server base URL: `http://localhost:3000`

The terminal should display:

```text
Student Record Management API is running on port 3000
```

The data is stored only in memory. It resets to the three initial records whenever the server restarts.

| name | String |
| branch | String |

## Required API endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/students` | Get all students |
| POST | `/api/students` | Add a student |
| GET | `/api/students/:id` | Get student by generated numeric ID |
| PUT | `/api/students/:id` | Update student by generated numeric ID |
| DELETE | `/api/students/:id` | Delete student by generated numeric ID |
| GET | `/api/students/filter?branch=value` | Filter by branch |

The filter is case-insensitive. If no student matches, the API returns an empty array with HTTP 200.

## Sample POST body

In Postman, select **Body → raw → JSON**:

```json
{
  "rollNumber": "IT2404",
  "name": "Meera Gupta",
  "branch": "IT",
  "semester": 3,
  "email": "meera@example.com"
}
```

Expected status: `201 Created`.

## Sample PUT body

Send this to `PUT /api/students/201`:

```json
{
  "rollNumber": "CSE2401",
  "name": "Aarav Sharma",
  "branch": "CSE",
  "semester": 4,
  "email": "aarav.sharma@example.com"
}
```

Expected status: `200 OK`.

## Postman testing checklist

Use `http://localhost:3000` as the base URL.

1. `GET /api/students`
2. `POST /api/students` with the sample POST body.
3. `GET /api/students/201`
4. `PUT /api/students/201` with the sample PUT body.
5. `DELETE /api/students/203`
6. `GET /api/students/filter?branch=CSE`
7. Test a branch with no matches, such as `ME`, and verify `[]` with status 200.
8. Test an invalid ID such as `999` and an invalid request body.

Expected status codes:
- `200 OK` – successful GET, PUT, DELETE, and filter.
- `201 Created` – successful POST.
- `400 Bad Request` – invalid ID format or invalid request body.
- `404 Not Found` – valid numeric ID that does not exist, or unknown endpoint.

Save screenshots of your Postman tests in the `screenshots` folder.
